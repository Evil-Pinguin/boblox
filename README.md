# boblox — ROBLOX GAME JAM

Интерактивная презентация (сейчас День 1 и День 2: 42 слайда (переключатель `DAYS_ENABLED` в `js/slides.js`: 1 — только День 1)) для двухдневного джема: **смотришь слайд → делаешь действие → получаешь часть своей игры**.

На каждом слайде внизу есть панель «⚡ Твоё действие» и «🎁 Получишь». Выполнил действие — получил «блок игры» (название, жанр, карта, стиль, катсцена, фишка, секретка, финал…). Блоки (по одному на слайд) собираются в готовую игру: вверху всегда виден прогресс («ТВОЯ ИГРА СОБРАНА НА 32%»), а когда собраны все блоки и нажато «Опубликовать», открывается финальный экран **GAME COMPLETE** с названием игры, жанром, стилем, фишкой, секреткой, Lua, AI и именем автора.

Слайды 22–25 и 32, 35 — «Тренажёр Lua»: шесть уроков, **59 заданий** для маленьких детей по схеме «сначала пример → потом повтори по примеру» (пример всегда на экране, ребёнок меняет одну деталь). Типы заданий: вставь слово, впиши своё, выбери ответ, собери строки по порядку. Уроки: 1 — print, переменные, числа, склейка слов; 2 — цвет, прозрачность, размер, Anchored; 3 — «если — то», Touched, лава-ловушка; 4 — скрипт подбора предмета с очками. В конце уроков 2–4 ребёнок получает готовый скрипт со своими словами и копирует его в Roblox Studio. Уроки лежат в `js/lessons.js`. Это не настоящий Roblox.

## День 1 / День 2

**День 1 — СОЗДАЁМ (слайды 1–25 + итог 26):** идея, жанр, мир, карта, Roblox Studio, Assistant, уроки Lua 1–4.
**День 2 — ЗАПУСКАЕМ (слайды 27–42):** план дня, катсцена и её показ в Studio (ScreenGui), главная механика, урок Lua 5 (for, task.wait, while — мигающая лампа), фишка, секретка, урок Lua 6 (CanCollide, ClickDetector, not — дверь с ключом), финиш, Dev Stand, тестирование, публикация (File → Publish to Roblox), настройка доступа (Private / Friends / Public), отзыв игрока и финальный экран GAME COMPLETE.

Между днями стоит слайд «Итог Дня 1» с собственным экраном DAY 1 COMPLETE. Всего 6 уроков Lua и 59 заданий. Публикация и доступ описаны по документации Roblox: новая игра по умолчанию приватная, настройка Audience находится в Creator Hub → Configure → Settings.

## Запуск

Сборка не нужна — это статический сайт:

```bash
python3 serve.py 8000   # сервер без кэша
# открыть http://localhost:8000
```

## Управление

| Клавиша | Действие |
| --- | --- |
| `←` `→` / `Пробел` | слайды |
| `Enter` | забрать блок, если действие выполнено |
| `G` | «Моя игра» — все блоки |
| `F` | полный экран |

Прогресс и ответы сохраняются в браузере (`localStorage`). Сброс — кнопка 🧱 → «Начать заново».

## Структура

- `index.html` — каркас
- `js/slides.js` — **весь контент**: тексты слайдов, действия и награды (удобно править)
- `js/lessons.js` — уроки Lua (шаги, ответы, подсказки)
- `js/lesson-ui.js` — интерфейс урока
- `js/app.js` — движок: навигация, поля ввода, блоки, награды
- `css/style.css` — оформление

## Порядок слайдов

Порядок задаётся списками `DAY1_IDS` / `DAY2_IDS` в начале `js/slides.js`. Прогресс хранится по `id` слайда, поэтому слайды можно добавлять и переставлять, ничего не ломая. Слайды-объяснения (правила джема, команда, ИИ, окна Studio, Part, куда класть Script) заканчиваются мини-проверкой из одного вопроса.

## Тема оформления

Кнопка ☀/🌙 в верхней панели (или клавиша `T`) переключает светлую и тёмную тему. Выбор сохраняется в `localStorage` (`boblox-theme`), по умолчанию — тёмная. Цвета вынесены в CSS-переменные в `:root`, светлая тема переопределяет их в `html[data-theme="light"]` в конце `css/style.css`. Блоки кода, лицензия и финальный экран остаются тёмными в обеих темах.

## Картинки

- `assets/ai/` — иконки Алисы (Яндекс) и ГигаЧата (Сбер) для слайдов про ИИ (ссылки: alice.yandex.ru и giga.chat); иконки найдены в интернете, права принадлежат их владельцам.
- `assets/genres/` — кадры из игр Roblox для карточек жанров (слайд «Жанр»), найдены в интернете и уменьшены до 480×270. Источники: Tower of Hell (reddit r/roblox), Piggy (reddit r/RobloxPiggy), Doors (pockettactics.com), Terminal Escape Room (escapistmagazine.com), Rivals (карточка игры в Roblox, через lootbar.com), Pet Simulator 99 (миниатюра игры, rolimons.com), Natural Disaster Survival (страница игры, reddit r/roblox), Barry's Prison Run (App Store, iofreeonline.com). Права на кадры принадлежат их авторам и Roblox; используются как иллюстрации в обучающей презентации.

## Номера слайдов

В левом верхнем углу каждого слайда стоит номер (`.slide-no`), он добавляется автоматически в `js/app.js`.

## ИИ

Слайд «AI как соавтор» ведёт детей в Алису и ГигаЧат (карточки со ссылками, открываются в новой вкладке). После слайда «Создаём карту» идёт слайд «ИИ прямо в Roblox Studio» про встроенного помощника Assistant (кнопка Assistant справа вверху в Studio). Список ИИ-сервисов — `AI_LINKS` в `js/slides.js`.

## Тренажёр по Lua (отдельная кнопка)

Зелёная кнопка **«⌨️ Тренажёр Lua»** есть в верхней панели на каждом слайде, а также на обложке (горячая клавиша **L**). Она открывает отдельный экран со всеми 6 уроками, выстроенными от простого к сложному: 🌱 легко (уроки 1–2), 🌿 средне (3–4), 🌳 сложно (5–6). Уроки открываются по порядку (есть кнопка «Открыть все уроки сразу»). Прогресс общий со слайдами. Код — `js/lua-hub.js`.

## Мобильная версия

На телефоне (экран уже 640 px или вертикальная ориентация) включается режим `html.m`: сцена 1280×720 больше не масштабируется, слайды идут в одну колонку и листаются прокруткой, стрелки «‹ ›» плавают внизу экрана. Стили — `css/mobile.css`, переключение — `fit()` в `js/app.js`. На ноутбуке и на телефоне в горизонтальном положении остаётся прежняя сцена с масштабом.

## Деплой на Vercel

Сайт статический, сборка не нужна: в репозитории есть `vercel.json` (корень проекта = папка с `index.html`, Framework Preset — Other, Build Command и Output Directory оставить пустыми/`.`). Vercel собирает ветку, указанную как Production Branch (обычно `main`), а остальные ветки и PR получают preview-ссылки.
